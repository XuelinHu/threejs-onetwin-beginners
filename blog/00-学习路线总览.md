# Three.js 新手学习路线

从一个圆、一个方块开始，先学会修改参数，再搭建自己的三维场景，最后拆解五个综合案例。按下面的顺序点击教程，每一步都有可操作的任务和完成标准。

第一次来这里，先打开[第 1 课：第一张画面与第一行代码](../threejs-learning-lab/#first-scene)。如果还没有下载项目，先读[克隆与本地启动教程](../docs/THREEJS-LEARNING-GUIDE.html)。

## 1. 准备项目：克隆与启动

已经通过局域网打开课程的同学，可以直接进入下一步。想在自己的电脑上修改代码，先安装 Git 和 Node.js 18 或更新版本，然后在终端执行：

```powershell
git clone https://github.com/XuelinHu/threejs-onetwin-beginners.git
cd threejs-onetwin-beginners
git lfs install
git lfs pull
node server.mjs
```

GitHub 版本的模型使用 Git LFS。国内网络也可以从 [Gitee 仓库](https://gitee.com/XuelinHu/threejs-onetwin-beginners)克隆；完整说明见[克隆与启动教程](../docs/THREEJS-LEARNING-GUIDE.html)。

启动后，在自己的浏览器输入 `http://127.0.0.1:8760/`。只需启动仓库根目录的一个服务，五个案例和学习工坊共用它。

完成标准：能打开[课程首页](../)，并从首页进入学习工坊。

## 2. 第一节课：修改欢迎语

打开[第一张画面与第一行代码](../threejs-learning-lab/#first-scene)，先观察中间的三维预览，然后点击“查看代码”。

1. 找到 `const message = '你好，Three.js！';`。
2. 把引号里的文字改为“我的第一个三维作品”。
3. 点击“运行并查看效果”，返回预览。
4. 对照右侧的关键 API，认识 `Scene`、`Camera`、`Renderer` 分别负责什么。

完成标准：画面中的文字已变成自己输入的内容，方块仍正常显示。

## 3. 基础教程：圆、方块、相机与贴图

按顺序学习，每节课只改一两项参数并观察结果。课程链接会直接打开对应章节。

| 顺序 | 点击进入教程 | 这节课要做什么 | 完成标准 |
| --- | --- | --- | --- |

| 2 | [画一个方块](../threejs-learning-lab/#draw-box) | 修改长、宽、高 | 能区分平面与三维物体 |
| 3 | [坐标与位置](../threejs-learning-lab/#coordinates) | 分别修改 X、Y、Z | 能把物体移动到指定位置 |

| 6 | [组合物体](../threejs-learning-lab/#groups) | 用多个几何体拼一张桌子 | 能整体移动一组物体 |

## 4. 拖拽练习：搭建一个自己的场景

打开[拖拽组件搭建练习](../threejs-learning-lab/drag-lab/?preset=basics)。

1. 从左侧拖入一个方块，再拖入一个圆柱和一盏灯。
2. 选择方块，在右侧修改位置、旋转、缩放和材质参数。
3. 使用撤销、重做，比较修改前后的效果。
4. 打开生成代码，对照 `position`、`rotation`、`scale` 和材质参数。
5. 保存场景 JSON，或者下载独立项目，在本地运行自己的作品。

完成标准：场景里有三个不同的对象，能保存、重新导入，并说明其中两项参数的用途。

## 6. 每个案例都按这四步学习

1. 阅读详细教程的“本课学习目标”，打开单项练习，确认模型或图表正常显示。
2. 找到 `practice.mjs` 和 `source/template.json`，先改一个参数或样例数字。
3. 保存并刷新，比较预期结果与实际结果，记录修改的文件和参数。
4. 打开完整案例，再阅读 `replica.mjs` 的对应部分，尝试在自己的独立项目中实现同一种功能。

例如学工业控制，先确认动画能播放，再读 `AnimationMixer` 和 `AnimationAction`，最后完成启动、停止和复位；学展厅时，先学相机与键盘移动，再理解重力与碰撞。

## 7. 音效与下一步练习

五个案例的音效保存在项目本地。进入案例后使用右下角音效面板启用、试听和调节音量，再操作设备、按钮或人物。浏览器需要先收到一次点击，才能允许网页发声。

音效的使用与替换方法见[音效教程](../docs/THREEJS-LEARNING-GUIDE.html#section-5)。完成后，给自己的独立项目加一个按钮音、运行提示音或脚步声，并在素材说明中保留来源与许可。

每个案例的 `AI_PROMPT.md` 是依据模板整理的复现提示词。可以把它交给 Codex，先生成一个独立项目，再逐项检查画面、交互和代码；原模型和配置是否使用，应在练习记录中写清楚。

## 8. 遇到问题时先检查什么

| 现象 | 检查与处理 |
| --- | --- |
| 页面打不开 | 确认根目录服务正在运行，地址含 `:8760` |
| 教程链接跳到别的电脑 | 使用本教程的相对链接，始终沿用当前访问地址 |
| 模型不出现 | 确认 Git LFS 素材已下载，查看页面加载提示和浏览器网络请求 |
| 画面卡顿 | 关闭其他大型场景，降低分辨率或像素倍率；网页由访问端浏览器渲染 |
| 没有声音 | 点击页面，检查案例音效面板、浏览器标签页静音和系统音量 |
| 修改后没变化 | 保存文件后用 `Ctrl+F5` 刷新，确认修改的是当前运行目录 |

需要从头查看操作步骤时，返回[克隆与本地启动教程](../docs/THREEJS-LEARNING-GUIDE.html)；准备开始第一节课时，点击[第一张画面与第一行代码](../threejs-learning-lab/#first-scene)。
