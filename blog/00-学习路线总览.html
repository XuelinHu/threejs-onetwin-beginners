Three.js 新手学习路线

从一个圆、一个方块开始，先学会修改参数，再搭建自己的三维场景，最后拆解五个综合案例。按下面的顺序点击教程，每一步都有可操作的任务和完成标准。

第一次来这里，先打开第 1 课：第一张画面与第一行代码。如果还没有下载项目，先读克隆与本地启动教程。

1. 准备项目：克隆与启动

已经通过局域网打开课程的同学，可以直接进入下一步。想在自己的电脑上修改代码，先安装 Git 和 Node.js 18 或更新版本，然后在终端执行：

GitHub 版本的模型使用 Git LFS。国内网络也可以从 Gitee 仓库克隆；完整说明见克隆与启动教程。

启动后，在自己的浏览器输入 http://127.0.0.1:8760/。只需启动仓库根目录的一个服务，五个案例和学习工坊共用它。

完成标准：能打开课程首页，并从首页进入学习工坊。

2. 第一节课：修改欢迎语

打开第一张画面与第一行代码，先观察中间的三维预览，然后点击“查看代码”。

  1. 找到 const message = '你好，Three.js！';。
  2. 把引号里的文字改为“我的第一个三维作品”。
  3. 点击“运行并查看效果”，返回预览。
  4. 对照右侧的关键 API，认识 Scene、Camera、Renderer 分别负责什么。

完成标准：画面中的文字已变成自己输入的内容，方块仍正常显示。

3. 基础教程：圆、方块、相机与贴图

按顺序学习，每节课只改一两项参数并观察结果。课程链接会直接打开对应章节。

顺序点击进入教程这节课要做什么完成标准
1画一个圆修改半径和颜色能说出几何体、材质和 Mesh 的关系
2画一个方块修改长、宽、高能区分平面与三维物体
3坐标与位置分别修改 X、Y、Z能把物体移动到指定位置
4透视相机改变观察位置和视场角能解释物体为什么变大或变小
5鼠标观察拖动、平移、缩放能围绕物体观察并恢复视角
6组合物体用多个几何体拼一张桌子能整体移动一组物体
7材质与光照修改金属度、粗糙度和光强能解释表面明暗的变化
8图片贴图与UV 重复给方块贴图、铺地砖能设置贴图重复次数
9动画调整每帧旋转速度能让物体持续运动

完整工坊包含 28 节基础课和 15 节综合课。左侧是目录，中间是运行预览，右侧是关键 API 与参数解释；完整代码通过弹框查看。

4. 拖拽练习：搭建一个自己的场景

打开拖拽组件搭建练习。

  1. 从左侧拖入一个方块，再拖入一个圆柱和一盏灯。
  2. 选择方块，在右侧修改位置、旋转、缩放和材质参数。
  3. 使用撤销、重做，比较修改前后的效果。
  4. 打开生成代码，对照 position、rotation、scale 和材质参数。
  5. 保存场景 JSON，或者下载独立项目，在本地运行自己的作品。

完成标准：场景里有三个不同的对象，能保存、重新导入，并说明其中两项参数的用途。

5. 五个案例：先读教程，再打开练习

推荐先从模型较小的设备运维开始，再进入车间、产线和大型展厅；智慧能源用来学习二维图表与业务数据。每篇教程都包含运行方法、关键代码、动手任务与排错说明。

推荐顺序详细教程先做单项练习再看完整案例独立综合课
1设备运维：模型与图表单模型取景设备运维系统从几何体搭建设备
2GMP 制药车间：场景与面板模型、相机与动画制药车间搭建车间布局
3工业控制：动画启停加载与摆放产线工业控制启动、停止和复位
4绿色展厅：环境与漫游展厅模型与相机绿色主题展厅键盘漫游与边界
5智慧能源：趋势与流向ECharts 数据绑定智慧能源能量沿曲线流动

每篇教程顶部还提供“基础练习”“组件拆解”和“拖拽搭建”入口，可以随时切换。完整案例使用原站公开组件与本地模型；学习工坊和教学练习使用另写的简化实现，适合一步步理解原理。

绿色展厅使用压缩后的模型，约 58.41 MB（55.71 MiB）。先只打开一个大型场景，等模型加载完成，再体验漫游。

6. 每个案例都按这四步学习

  1. 阅读详细教程的“本课学习目标”，打开单项练习，确认模型或图表正常显示。
  2. 找到 practice.mjs 和 source/template.json，先改一个参数或样例数字。
  3. 保存并刷新，比较预期结果与实际结果，记录修改的文件和参数。
  4. 打开完整案例，再阅读 replica.mjs 的对应部分，尝试在自己的独立项目中实现同一种功能。

例如学工业控制，先确认动画能播放，再读 AnimationMixer 和 AnimationAction，最后完成启动、停止和复位；学展厅时，先学相机与键盘移动，再理解重力与碰撞。

7. 音效与下一步练习

五个案例的音效保存在项目本地。进入案例后使用右下角音效面板启用、试听和调节音量，再操作设备、按钮或人物。浏览器需要先收到一次点击，才能允许网页发声。

音效的使用与替换方法见音效教程。完成后，给自己的独立项目加一个按钮音、运行提示音或脚步声，并在素材说明中保留来源与许可。

每个案例的 AI_PROMPT.md 是依据模板整理的复现提示词。可以把它交给 Codex，先生成一个独立项目，再逐项检查画面、交互和代码；原模型和配置是否使用，应在练习记录中写清楚。

8. 遇到问题时先检查什么

现象检查与处理
页面打不开确认根目录服务正在运行，地址含 :8760
教程链接跳到别的电脑使用本教程的相对链接，始终沿用当前访问地址
模型不出现确认 Git LFS 素材已下载，查看页面加载提示和浏览器网络请求
画面卡顿关闭其他大型场景，降低分辨率或像素倍率；网页由访问端浏览器渲染
没有声音点击页面，检查案例音效面板、浏览器标签页静音和系统音量
修改后没变化保存文件后用 Ctrl+F5 刷新，确认修改的是当前运行目录

需要从头查看操作步骤时，返回克隆与本地启动教程；准备开始第一节课时，点击第一张画面与第一行代码。
