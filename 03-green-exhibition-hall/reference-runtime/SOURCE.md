# 原站组件对照运行库

来源：https://onetwin.cn/ 的公开浏览器运行文件；仅作为本地原版对照使用。该目录中的压缩组件代码来自 OneTwin，并非本教程作者原创。原始下载地址、大小和 SHA-256 见 sources.json；未修改代码另存于项目工具目录 tools/.reference-originals。

本地适配包括：移除网站启动、登录与远端配置读取，导出本地挂载入口；把网站根路径改为目录内路径；模型直接通过本地 HTTP 加载，省去原站 IndexedDB 二次缓存；导出只供验收的场景引用。模板中的两张原站不可用的管线小图以透明像素代替，不影响管线与数据；天气保留原站外部服务。

教材的可读示例独立保存在各案例 practice.mjs 和 lesson.html；replica.html 是另写的简化运行器，不能代替原版组件对照。模型和模板来源见各案例 source/。素材与运行库的商业再分发授权需向各权利人确认。
